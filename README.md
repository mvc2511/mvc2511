### 🎓 Acerca de mí

Soy **Ingeniero en Desarrollo y Gestión de Software** (Universidad Tecnológica Tula-Tepeji) y actualmente trabajo como **Software Engineer en Ford Motor Company**.

- **Backend:** servicios escalables con Spring Boot (Java), .NET y Node.js; APIs REST y GraphQL.
- **Frontend y móvil:** Angular, React, Next.js y React Native con Expo.
- **Arquitectura:** Clean Architecture, Domain-Driven Design, microservicios y serverless.
- **Cloud y DevOps:** GCP (Cloud Run) y AWS (Lambda, SQS, EventBridge), Terraform, CloudFormation y CI/CD con Tekton.
- **IA:** automatización de procesos de negocio con agentes inteligentes y APIs de LLM.

📍 Naucalpan, Estado de México · 🌎 Español (nativo), Inglés (B1)
